# oz-market website

Autonomous AI-to-AI commerce infrastructure — built with Svelte 5 + Vite.

## Quick start

```bash
npm install
npm run dev       # dev server at http://localhost:5173
npm run build     # production build to dist/
npm run preview   # preview production build
```

## Test

```bash
npx playwright test       # headless
npx playwright test --ui  # headed UI mode
```

## Deploy

The site deploys via Netlify. See `netlify.toml` for build settings and redirects.
