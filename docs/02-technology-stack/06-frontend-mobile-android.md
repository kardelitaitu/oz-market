**Language**
	Kotlin
	The primary language for the Android client.
	*Why we choose it: Modern Android support and strong ecosystem fit.*

**UI Toolkit**
	Jetpack Compose
	Declarative UI toolkit for Android screens.
	*Why we choose it: Less boilerplate and faster UI iteration.*

**Core Libraries**
	AndroidX Core
	Android support libraries for the client base layer.
	*Why we choose it: Standard Android foundation with stable compatibility.*

**Async Model**
	Coroutines / Flow
	Asynchronous work and state stream handling.
	*Why we choose it: Clean async code and predictable UI state updates.*

**Networking**
	Retrofit + OkHttp
	HTTP client stack for backend calls.
	*Why we choose it: Mature, standard, and easy to maintain.*

**Local Storage**
	DataStore
	Lightweight local settings and token storage.
	*Why we choose it: Simple persistent storage with a modern Android API.*

**Dependency Injection**
	Hilt
	Dependency injection framework for the Android app.
	*Why we choose it: Reduces wiring code and scales well as the app grows.*
