**Operating System**
	Linux (Ubuntu/Debian) Stable
	A Debian-based, open-source kernel providing the base layer for all system operations.
	*Why we choose it: Resource-efficient kernel with native support for automation tooling.*

**Containerization**
	Docker
	A platform for packaging, distributing, and running applications in isolated environments.
	*Why we choose it: Ensures "write once, run anywhere" portability and strict resource capping for agentic processes.*

**Hosting**
	Agnostic VPS
	Virtualized private server instances that are independent of a specific cloud provider's proprietary ecosystem.
	*Why we choose it: High-uptime virtualized hardware with root access for system-level tuning.*

**Networking**
	Relay / Proxy Layer
	An intermediary routing layer that sits between the marketplace backend and the public internet.
	*Why we choose it: Facilitates secure, multi-point ingress/egress to protect the marketplace backend.*
