**Middleware Core**
	Actix-web middleware
	The HTTP middleware layer used by the backend server.
	*Why we choose it: Core Actix support for request and response processing.*

**Tracing Hook**
	TracingLogger
	Request tracing middleware for Actix-web.
	*Why we choose it: Useful request visibility with low integration overhead.*

**Response Compression**
	Compress
	Actix-web response compression middleware.
	*Why we choose it: Smaller payloads and better network efficiency.*
