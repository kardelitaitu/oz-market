**Language**
	Swift
	The primary language for the iOS client.
	*Why we choose it: Native iOS support and a strong Apple ecosystem fit.*

**UI Toolkit**
	SwiftUI
	Declarative UI toolkit for iOS screens.
	*Why we choose it: Faster UI iteration with less boilerplate.*

**Core Frameworks**
	Foundation
	The base Apple framework layer for the client.
	*Why we choose it: Standard iOS foundation with stable APIs.*

**Async Model**
	Swift Concurrency
	Async/await and structured concurrency for iOS work.
	*Why we choose it: Clean asynchronous code and predictable state handling.*

**Networking**
	URLSession + Codable
	HTTP client stack for backend calls and JSON models.
	*Why we choose it: Native, standard, and easy to maintain.*

**Local Storage**
	Keychain
	Secure local storage for tokens and sensitive app data.
	*Why we choose it: Native secure storage with minimal moving parts.*

**Caching**
	Core Data
	Local data caching layer for read-heavy app state.
	*Why we choose it: Mature Apple persistence option for offline-friendly UX.*
